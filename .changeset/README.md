# Changesets

Every change to a package needs a changeset. Run `npx changeset`, pick patch or minor, and write one line for the changelog. Commit the generated file with your change.

`@flxra/tokens` and `@flxra/ui` share one version number (`fixed`), so a changeset for either releases both.

While Flxra is `0.x`: **minor** for breaking changes, **patch** for everything else.
